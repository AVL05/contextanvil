# Relevance v2 pilot protocol

Frozen before evaluation. The labels were generated by the existing mechanical
selector on 80-commit shallow clones. The JSON pins the history heads and each
parent snapshot. All five repositories are independently maintained and MIT
licensed at their pinned heads (license files: ky `license`, Laravel framework
`LICENSE.md`, and `LICENSE` in Preact, Express and Underscore).

Ky and Preact are development repositories. Laravel framework, Express and
Underscore are a repository-disjoint pilot holdout. Do not tune after opening
the holdout. The selector uses commit subjects and existing modified/deleted
files. Classifier-eligible changed files are weak positive labels. They may
include incidental edits and omit essential unchanged files. No independently
adjudicated essential labels are available in this pilot. Pack changed-file
coverage is a proxy only and cannot satisfy the essential-file release gate.

Compare Phase 1.2 (lexical mode) with experimental v2 on the same snapshots.
Report candidate recall at 64, P@1, MRR, R-precision, changed-file coverage at
8 KiB, pack bytes, fresh-process and warm timings, peak RSS and repeat-output
determinism. For uncertainty resample repositories with paired results, keeping
all tasks in each sampled repository. Report exploratory 95% intervals and
repository-level effects. Three holdout repositories cannot establish
generalization. The design's +10 point candidate and +5 point essential
coverage targets still govern promotion.
