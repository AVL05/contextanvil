# CLAUDE.md

This repository keeps its agent instructions in `AGENTS.md`, so that every coding agent reads the same
rules. Read `AGENTS.md` first and follow it: it covers commands, architecture layering and the
non-negotiable safety rules for this project.

## Claude Code notes

- Run `npm test` before reporting a change as complete, and report the real result.
- Prefer the targeted command `node --test test/<file>.test.js` while iterating.
- Do not add attribution, branding or claims to documentation that the code does not back up.
